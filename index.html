HaproID API

Access public HaproID profile data through a simple JSON endpoint. Use it to display profiles and integrate HaproID data into your projects.

Checking API...

API Endpoint

Use this URL to retrieve profile directory data.

GET https://haproid-hub.vercel.app/assets/json/users-list.json

Data Fields

A profile may contain the following information:

Field Description
idUnique profile ID
nameDisplay name
emailPublic email, if available
phonePublic phone, if available
dateRegistration date
lastUpdatedLast update date
roleProfile role
locationProfile location
statusProfile status
bioProfile description
profileProfile page URL or path
img / imageProfile image path
skillsSkills array
featuredFeatured status (Boolean)

Usage

Fetch and read the JSON data using JavaScript:

fetch("https://haproid-hub.vercel.app/assets/json/users-list.json")
    .then(response => response.json())
    .then(data => console.log(data))
    .catch(error => console.error(error));

Filter Featured Profiles

fetch("https://haproid-hub.vercel.app/assets/json/users-list.json")
    .then(response => response.json())
    .then(data => {
        const users = data.filter(
            user => user.featured === true
        );
        console.log(users);
    });

Display User Cards

Display HaproID profiles on your website using HTML, CSS and JavaScript. Follow these steps.

1. Add HTML

Create a container where the user cards will appear.

<div id="usercard"></div>

2. Add CSS

Style the profile cards.

.user-grid {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
    gap: 15px;
}

.user-card {
    border: 1px solid #e2e8f0;
    border-radius: 12px;
    padding: 16px;
}

.user-card img {
    width: 100px;
    height: 100px;
    object-fit: cover;
    border-radius: 50%;
}

.user-card p {
    color: #64748b;
    font-size: 14px;
}

3. Add JavaScript

Fetch profiles and display them. Profiles with featured: false will be hidden. 

fetch("https://haproid-hub.vercel.app/assets/json/users-list.json")
    .then(res => res.json())
    .then(users => {
        document.getElementById("usercard").innerHTML = users
            .filter(user => user.featured !== false)
            .map(user => `
                <div class="user-card">
                    <img src="${'https://haproid.netlify.app' + (user.img || user.image)}" alt="${user.name || 'User'}">
                    <h3>${user.name || "Unknown"}</h3>
                    <p>${user.role || ""}</p>
                    <p>${user.location || ""}</p>
                    <p>${user.bio || ""}</p>
                    <a href="${user.profile || '#'}">Profile</a>
                </div>
            `).join("");
    })
    .catch(error => {
        document.getElementById("usercard").innerHTML =
            "<p>Unable to load users.</p>";
        console.error(error);
    });

Notes

This is a public read-only endpoint. No authentication is required. Fields may differ between profiles. Handle missing data and API errors in your application. Use profile data responsibly.

About HaproID

HaproID is a digital profile identity and directory initiative within the Haproven ecosystem, helping people discover profiles and profile information.
