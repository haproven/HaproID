HaproID API

Access public HaproID directory data through a simple JSON endpoint. Built for developers and applications.

Public endpoint

API Endpoint

GET https://haproid-hub.vercel.app/assets/json/users-list.json

Example Response

[
  {
    "id": "pro-susheel-01",
    "name": "Susheel Kumar",
    "role": "Full Stack Developer",
    "location": "Bihar, India",
    "status": "Team",
    "profile": "/user/pro-susheel-01/",
    "featured": true
  }
]

Usage

Fetch the JSON data directly using JavaScript: 

fetch("https://haproid-hub.vercel.app/assets/json/users-list.json")
  .then(response => response.json())
  .then(data => console.log(data))
  .catch(error => console.error(error));

About HaproID API

HaproID API provides publicly accessible profile directory data in JSON format for integration, profile discovery and developer projects. No authentication is required for this public endpoint.
